# Pichanga - Development Guidelines

## Preferred Tech Stack

Always use the following tools and services when developing this project:

| Tool | Purpose |
|------|---------|
| **Claude** | Programming / code generation |
| **Supabase** | Backend + database |
| **Vercel** | Deployment |
| **Spaceship** | Domain management |
| **Stripe** | Payments |
| **GitHub** | Version control |
| **Resend** | Emails |
| **Clerk** | Authentication |
| **Cloudflare** | DNS |
| **PostHog** | Analytics |
| **Sentry** | Error tracking |
| **Upstash** | Redis |
| **ChatGPT** | Creative ideation / vibes |
| **Pinecone** | Vector database |
